# Kahve Falı Uzmanı Ama Aslında Rastgele Sayı Üreten Şey

## Bu Nedir?

Bu, insanlık tarihinin en ciddi, en bilimsel, en doğru kahve falı bakan yazılımıdır. 

Türk kahvesinin dibindeki telveyi analiz eder, evrenin sırlarını çözer, geleceği görür. 

Aslında hiçbir şey yapmaz. Sadece `random.randint` çağırır ve size abuk sabuk laflar söyler. Ama bunu o kadar ciddi bir şekilde yapar ki, siz de inanırsınız.

## Neden Bu Proje Var?

Çünkü birisi “absürt bir repo aç” dedi. İşte açtık. Anlamı yok. Olması da gerekmiyor. Sadece Türkçe.

## Nasıl Kullanılır?

```bash
python fal_bakan_sihirli_script.py
```

Sonra doğum yılını gir. Fincanını masaya koy (kod görmez ama sen koy). Bekle. Falın gelir.

## Özellikler

- %100 gerçek kahve falı deneyimi (kahve yok)
- Rastgele sayı üretimi ile desteklenen yapay zeka
- Türkçe fal mesajları
- Ciddi görünen ama aslında komik
- Kahve içmeden çalışmaz (aslinda çalışır)
